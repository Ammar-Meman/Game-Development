# RGB Color Guessing Game

Test your knowledge of RGB colors! The game gives you an RGB color value, and you have to guess which color box matches it. 

## Features
- **Difficulty Modes:** Play in Easy mode (fewer options) or Hard mode (more options).
- **Lifelines:** Keep track of your mistakes with a heart-based lifeline system.
- **Streak Counter:** Tracks your current winning streak and your all-time best streak.

## Technologies Used
- HTML
- CSS
- JavaScript
