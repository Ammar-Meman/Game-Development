# Click Counter Game

A simple and fun game to test your clicking speed! Try to get as many clicks as you can within the time limit. 

## Features
- **Time Limit:** Challenge yourself to click as many times as possible before the timer runs out.
- **Score Tracking:** Keeps track of your current score and your highest score.
- **Stats:** Displays your clicks per second in real-time.

## Technologies Used
- HTML
- CSS
- JavaScript
