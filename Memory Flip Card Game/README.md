# Memory Flip Card Game

A classic memory matching game using emojis! Flip the cards and find the matching pairs as quickly as possible.

## Features
- **Interactive Gameplay:** Flip cards to find matching emoji pairs.
- **Scoreboard:** Keeps track of your moves, matched pairs, and time taken.
- **High Score:** Saves your best score so you can challenge yourself again.

## Technologies Used
- HTML
- CSS
- JavaScript
